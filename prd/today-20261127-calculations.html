积分与代垫计算规则补充

日期：2026-11-27。关联：PRD_积分与预定今日更新_20261127。

本文件承载精确计算口径，金额示例不是演示数据写入指令。

积分

- 积分获取默认每 1,000 HKD 转码获得 1 点，按完整积分向下取整；获取条件设为 0 时不计算。

- 外币转码先按积分配置汇率折为 HKD；与系统资金换汇汇率区分。

- 默认有效期 90 天；0 为永久；专属期限优先。默认期限按包含发放当日计算，90 天到期日为发放日后第 89 天。

- 消耗按最早到期优先，再按发放时间与稳定顺序处理；永久积分排在有限期之后。

- 积分池期末 = 期初 + 财务新增 − 财务扣除 + 客户积分增加合计 − 客户积分减少合计。

- 客户手动扣除、预定支付、代垫还款和到期均同步扣减积分池；收工、手动添加和正向更正均同步增加积分池。

- 本月兑换 = 预定积分消耗 + 代垫积分还款消耗 + 手动扣除；不含积分到期。

- 最近到期数量为最近到期日各有效批次剩余之和。

- 日期边界、创建时间及统计月份采用 Asia/Shanghai。

代垫换算

债务类型还款来源换算
现金现金、HKD存款、他人HKD存款1 HKD抵还1 HKD
现金本人或他人积分积分 × 折数 = 抵还HKD；所需积分向上取整
积分本人或他人积分1点抵还1点
积分现金、存款、他人存款1 HKD抵还1点
任一公司赠送按债务原单位减免，不扣客户余额

- 现金代垫积分还款折数默认 0.6；设置允许 0—1。折数为 0 时不得以除零方式计算偿还数量，相关积分还现金路径应提示无法有效抵还。

- 货币界面采用“万”；1 万 = 10,000 原币单位。

- 外币存款需使用系统配置汇率，与指定对手换 HKD 后还款；源币扣款按四位小数向上取整。

- 折抵不得超过待还；积分整数进位带来的尾差不得使债务变成负数。

- 预填值不得超过付款方可用余额；可手动修改为有效部分还款。

- 多笔分配按预定时间由早到晚，逐笔抵还至耗尽本次额度。

- 确认页必须展示折数、币种与实际扣除，最终提交保存当时依据。

防重复与追溯

- 核对前、返回修改和关闭均不得记账。

- 最终提交失败时，不产生局部扣减或部分订单还款。

- 同一提交重复处理不得新增第二次扣减。

- 历史非HKD现金欠款需要明确换算基准后处理，不自动沿用本轮新增HKD债务口径。

最新确认：同向同步

- 所有新增客户积分流水必须同时产生一条同号业务关联的积分池流水，方向与数量完全相同。

- 客户增加10点，池增加10点；客户减少10点，池减少10点。

- 财务直接增减池仍仅调整池，不自动分配给客户。

- 新规则适用于之后的操作；历史流水不自动改写或补记。历史余额重算需另行确定范围。

- 失败及重复提交不产生额外联动流水；核对预览不记账。
