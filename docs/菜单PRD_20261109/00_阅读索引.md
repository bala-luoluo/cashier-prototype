## 重要待确认

- 收工上下数交收到底转换本单存卡金额，还是户口全部存卡。
- 公司批额不分币种后的跨币种债务占用规则。
- 多批次股价下的退股成本、可退金额和顺序。
- 隐藏占成多代理代垫补款路径与金额最小精度。
- 开工M单、额度M单、公司资金和客户余额的统一账本接入。

## 已明确取舍

| 主题 | 本包采用的最终规则 |
|---|---|
| 收工默认分配 | 剩余统一存卡，三个分配金额可编辑 |
| 中途存取 | 保留数值，隐藏计算说明 |
| 占成配置 | 三块并排，子订单层级独立 |
| 子订单操作 | 修改码粮比、结算佣金及三种支付操作同时保留，完成后查看记录 |
| 代理承担 | 自动承担规则待确认，不手动输入，当前仅预览支付走向 |
| 结算合计 | 列表下方紧凑展示，无顶部大卡片 |
| 公司额度 | 融入概况表格，不分币种独立一行 |
| M打印 | 列表、历史、还款弹窗均移除 |
| 负数管理 | 新增与移除留记录，不编辑、不显示列表确认人 |
